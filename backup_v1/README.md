# 🎯 CS2 Tactics Lab (MVP)

Мобильное веб-приложение для соревновательного CS2: карманный интерактивный справочник раскидок и AI Тактический Капитан.

## 🛠 Стек технологий
- **Frontend:** React 18 + TypeScript + Vite + Tailwind CSS
- **Стилизация:** CS2 Tactical Dark Theme (`#121214`, CS2 Amber `#f59e0b`, CS2 Blue `#38bdf8`)
- **Backend / Auth:** Supabase Auth & PostgreSQL с Row Level Security (RLS)
- **Нейросеть:** Google Gemini 1.5 Flash API (структурированная тактическая генерация)

---

## ⚡ Самый простой запуск приложения (1 клик):

В корне папки создан файл запуска для Windows:
👉 **Просто дважды кликните по файлу `start.bat`**

Скрипт автоматически:
1. Проверит наличие Node.js.
2. Установит все необходимые библиотеки (если они еще не установлены).
3. Автоматически откроет приложение в вашем браузере на `http://localhost:3000`.
4. Запустит dev-сервер.

*(Для пользователей PowerShell также доступен файл `start.ps1`)*

## 🚀 Реализованный функционал:

### ✅ 1. Мобильный интерфейс и карта Mirage (CS2 Subtick)
- Полный маппул (7 соревновательных карт): активен **Mirage** с 12 реальными раскидками (смоки в окно, билет, джингл, молотов в фаербокс и т.д.), остальные карты помечены бейджем «Скоро».
- Фильтры зон (A, Mid, B), сторон (T / CT), типов гранат (Смок, Молотов, Флеш, HE) и живой текстовый поиск.
- Детальные карточки с бейджами типа броска (`Jumpthrow`, `Stand & Throw`, `Run+Jumpthrow`), ориентирами прицела и точками падения.

### ✅ 2. Авторизация и облако Supabase с RLS
- Подключена библиотека `@supabase/supabase-js`.
- Авторизация по Email и паролю (Вход и Регистрация).
- Сохранение «В избранное» и статуса «Выучено» в облачной таблице `user_lineups` с политиками Row Level Security (RLS).
- Готовый SQL-скрипт в `supabase/schema.sql`.
- Режим моментального оффлайн/демо-тестирования в 1 клик.

### ✅ 3. AI Тактический Капитан (Google Gemini API)
- Подключен SDK `@google/generative-ai`.
- Вкладка «AI Тактик»: конфигуратор раунда (выбор стороны, ползунок 1–5 игроков, гранаты, цель раунда).
- Профессиональный киберспортивный IGL-системный промпт с учетом физики волюметрических смоков и таймингов Mirage.
- Формирование структурированного плана:
  - Распределение ролей и конкретных раскидок из базы для каждого игрока.
  - Посекундный тайминг броска гранат и входа на плент.
  - План «Б» (контр-меры при поджиме соперника).
- **Менеджер API-ключа прямо в интерфейсе:** можно вставить Gemini API-ключ в настройках мобильного экрана или в `.env` (`VITE_GEMINI_API_KEY`).
